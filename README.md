# GeyserSwap

統合版 (Geyser) プレイヤーが、Java 版 PvP の **属性スワップ** を疑似的に使えるようにする Paper プラグイン。
Paper 26.1 / 26.2 / 26.3 で動作確認済み (26.x 系向け、Java 25)。
26.2 では Geyser + Floodgate + 統合版 Bot (bedrock-protocol) で、統合版からの操作として実測している。

## 属性スワップとは

Java 版では、ホットバー切り替えと攻撃が同じ tick に届くと

- 攻撃力・攻撃速度などの **属性** は「切り替え前」のアイテム
- エンチャント (鋭さ・ブリーチ・火属性など)・耐久消費・メイスの落下ボーナスは「切り替え後」のアイテム
- 攻撃チャージも切り替え前のまま

で計算される。例: 剣 → 鋭さ V の棒に切り替えて殴ると 7 + 3 = 10 ダメージ。

統合版は切り替えと攻撃を 50ms 以内に揃えるのが難しいので、このプラグインは
**切り替えから猶予 (grace-ms) 以内の攻撃** を「同じ tick」とみなして、同じ計算にする。

> 補足: Paper の既定設定 `update-equipment-on-player-actions: true` (config/paper-global.yml) では、
> 持ち替えが即座に反映されるので **Java 版プレイヤーも属性スワップできない**。
> `/geyserswap bedrockonly false` にすると Java 版プレイヤーにも同じ猶予で使えるようになる。

## 統合版向けの追加の動き

| 機能 | 内容 | 設定 |
|---|---|---|
| 槍のリーチスワップ | 槍から持ち替えて猶予内に空振りすると、槍の `attack_range` で照準し直し、持ち替えた武器で殴る。統合版クライアントは 3 ブロックより遠い相手に攻撃を送らず空振りになるため | `spear-reach` |
| 空中延長 (メイス) | 空中でメイスへ持ち替えて落下攻撃になる場合は、着地するまで猶予を延長 (上限 `air-grace-max-ms`)。メイス以外・着地後は延長しない | `air-grace` / `air-grace-max-ms` |
| チャージの引き継ぎ | 猶予内に殴ったときだけ、持ち替えでリセットされた攻撃チャージを持ち替え前から溜めていた分で計算する。属性の差し替えとは独立 (ウィンドチャージ → メイスなど、切り替え前が武器でなくても効く) | `keep-attack-charge` |
| 武器のときだけ属性を差し替え | 切り替え前が武器でない (パール・ウィンドチャージ等) ときや、切り替え前の武器のほうが弱いときは属性を差し替えない。連続で持ち替えたときは途中で持った一番強い武器を使い、猶予は最後の持ち替えから数える | `only-stronger` |
| 槍のチャージスワップ (突進) | 槍は最低チャージ 1.0 (満タン) が無いと突けない。チャージの短い物で溜め切ってから槍に替え、猶予内に突くと、持ち替え前の攻撃速度とゲージで判定して突きを実行し直す。突進 (Lunge) も通常どおり出る | `keep-attack-charge` |
| 持ち戻しの無視 | スワップで殴った直後に元の武器へ戻した持ち替えはスワップにしない。しないと戻した武器の次の一撃がスワップ先の属性で弱くなる | `ignore-swap-back` |

## 導入

1. `build/libs/GeyserSwap-1.0.0.jar` を `plugins/` に入れる
2. 同じサーバーに Geyser-Spigot か Floodgate を入れておく
   (Geyser をプロキシ側に置く構成なら、バックエンドに Floodgate が必要)

## コマンド (OP / `geyserswap.admin`)

| コマンド | 内容 |
|---|---|
| `/geyserswap` | 現在の設定を表示 |
| `/geyserswap grace <ms>` | 猶予を変更 (0〜3000 ミリ秒)。`3t` のように tick でも指定できる (`3t` = 150ms)。外部のプレイヤーがいるなら 100 前後がおすすめ |
| `/geyserswap on` / `off` | 機能の ON/OFF |
| `/geyserswap keepcharge <true\|false>` | 切り替え前のチャージを引き継ぐか |
| `/geyserswap bedrockonly <true\|false>` | 統合版だけに適用するか |
| `/geyserswap spearreach <true\|false>` | 槍のリーチスワップ |
| `/geyserswap reachgrace <ms>` | 槍のリーチスワップの猶予 (初期値 200ms)。通常の猶予より長い方が使われる |
| `/geyserswap airgrace <true\|false>` | 空中延長 (メイス) |
| `/geyserswap airmax <ms>` | 空中延長の上限 (0〜10000) |
| `/geyserswap swapback <true\|false>` | 持ち戻しを無視するか |
| `/geyserswap stronger <true\|false>` | 切り替え前の武器が強いときだけ属性を差し替えるか |
| `/geyserswap debug <true\|false>` | 切り替え・攻撃・ダメージと、スワップが成立しなかった理由を本人のチャットとコンソールへ表示 |
| `/geyserswap reload` | config.yml を読み直す |

別名 `/gswap`。変更は `plugins/GeyserSwap/config.yml` に保存される。

## 実測 (Paper 26.1.2、Bot、ダイヤ剣 → 鋭さ V の棒、猶予 150ms)

| 状況 | ダメージ |
|---|---|
| 剣だけ / 棒だけ | 7.00 / 4.00 |
| 切り替え 100ms 後に攻撃 | **10.00** |
| 切り替え 300ms 後 (猶予外) | 4.00 |
| 猶予 0 / プラグイン OFF で 100ms 後 | 1.90 |
| 剣で殴って 300ms 後に切り替え、100ms 後に攻撃 | 6.03 (切り替えなしで同じ時間待った剣のチャージ 0.68 と一致) |

## 実測 (Paper 26.2 + Geyser + Floodgate、統合版 Bot)

| 状況 | ダメージ |
|---|---|
| 剣 → 鋭さ V の棒、100ms 後 / 同じ tick / 300ms 後 | **10.00** / **10.00** / 4.50 (猶予外) |
| 落下中に剣 → メイス、100ms 後 | **40.52** (剣 7 + 落下ボーナスの期待値 40.52 と一致) |
| 落下開始直後にメイスへ、5 ブロック落ちて攻撃 (空中延長 ON / OFF) | **44.99** / 27.56 |
| 空中で棒へ持ち替えて落下攻撃 (メイスでないので延長しない) | 4.50 |
| スワップ後に剣へ持ち戻して攻撃 (持ち戻し無視 ON / OFF) | 合計 13.99 / 11.00 |
| 槍 → 鋭さの棒、3.2 ブロック先へ空振り (ON / OFF) | **6.00** (槍 3 + 鋭さ 3) / 0 |

| ウィンドチャージ → メイス 100ms 後 (チャージ引き継ぎ ON / OFF) | 属性はメイスのまま、チャージ 1% → 100% / 7% (1.23) |
| メイス → 剣 100ms 後 (切り替え前が弱い) | 7.00 (剣の属性のまま、チャージ 20% → 100%) |

| 棒で溜め切る → 突進 III の槍 → 100ms 後に突く (ON / OFF) | 突進あり 水平速度 1.38 (槍だけで溜めた時の 1.37 と同等) / 突進なし |

着地後に延長されないことは Java 版 Bot で確認 (落下中 34.03 = 期待値、着地後 4.47 = 通常のメイス)。

## 制限

- `minimum_attack_charge` を持つアイテムへの切り替えは、Paper が攻撃前に弾くので対象外
- エンチャント由来の属性変更 (カスタムエンチャントの `attributes` 効果) は持ち越さない。バニラの武器には影響なし
- 攻撃のチャージ引き継ぎは `attackStrengthTicker` をリフレクションで書き換えている。見つからない版ではチャージ引き継ぎだけ無効になる
